# PictoChat Client

**Version:** 1.3.1 · **Coder:** quatric

Homebrew clients for [PictoChat Online](https://pict.chat) by ayunami2000: join the chat rooms, type with the DS keyboards and draw, from a console. They look, sound and behave like pict.chat, and you chat with everyone using the website. All the clients live in this one repository so a change can be made to every console at once.

| Console | Folder | Download | Install |
| --- | --- | --- | --- |
| Wii | [`wii/`](wii) | `PictoChat-Wii.zip` | Extract to the SD card or USB drive, open from the Homebrew Channel |
| Wii U | [`wiiu/`](wiiu) | `PictoChat-WUP.zip` | Extract to the SD card, open from the Wii U Menu (Aroma) |
| 3DS | [`3ds/`](3ds) | `PictoChat-3DS.zip` or `PictoChat-3DS.cia` | Extract to the SD card for the Homebrew Launcher, or install the CIA with FBI |

Grab the builds from the [latest release](../../releases/latest). Every push to `main` builds all three in one workflow and refreshes it.

See each folder's README for controls, settings and build instructions. Each client builds on its own with `make` from inside its folder.
